# Namefi plugin support

For help with the Namefi plugin for ChatGPT and Codex, email [support@namefi.io](mailto:support@namefi.io).

Please include the task you were trying to complete, the plugin version, and any error message. Do not send passwords, API keys, OAuth tokens, wallet recovery phrases, or payment details.

The plugin connects to Namefi's hosted MCP server for domain search, registration, and DNS management. If tools do not appear or return an authentication error, reconnect your Namefi account in the host app and retry once. For questions about a domain order or billing, include the order ID if one was returned.

The same support address can receive source issue reports and suggested improvements.
